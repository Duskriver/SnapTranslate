# 多结果窗口的真实 API 内存验证

2026-10-23，Apple Silicon、macOS 27.0.1、Swift 6.4 Release 优化。对同一公开英文选区执行 **7 次真实 DeepSeek 翻译**：第一轮保留 5 个结果并逐步关完，静置后再打开 2 个结果并关完。7 次均获得非空译文和「翻译完成」状态。

**结论：最后关窗后工作进程正常退出，内存回落。** 第一轮保留 5 个结果时两进程合计 47.33 MiB，关完约 49 秒后为 14.55 MiB；第二轮关完约 16 秒后为 14.53 MiB，与同一主进程冷启动 13.97 MiB 相差约 0.56 MiB。

## 逐阶段占用

单位为 MiB，使用当前 physical footprint。表中合计为主进程与工作进程相加，不含 XPC、GPU、WindowServer，未去重共享页；本次是一个新进程会话的实测值，不是多组中位数或资源上限。

| 状态 | 主进程 | 工作进程 | 两进程合计 |
| --- | ---: | ---: | ---: |
| 冷启动 | 13.97 | 0 | 13.97 |
| 保留 1 个完成结果 | 14.34 | 25.20 | 39.55 |
| 保留 3 个完成结果 | 14.58 | 29.39 | 43.97 |
| 保留 5 个完成结果 | 14.86 | 32.47 | 47.33 |
| 关到剩 3 个 | 14.63 | 31.66 | 46.28 |
| 关到剩 1 个 | 14.63 | 31.39 | 46.02 |
| 第一轮关完约 3.2 秒 | 14.63 | 0 | 14.63 |
| 第一轮关完约 16.8 秒 | 14.61 | 0 | 14.61 |
| 第一轮关完约 48.7 秒 | 14.55 | 0 | 14.55 |
| 重新打开 2 个完成结果 | 14.74 | 27.52 | 42.25 |
| 第二轮关完约 3.2 秒 | 14.94 | 0 | 14.94 |
| 第二轮关完约 15.6 秒 | 14.53 | 0 | 14.53 |

保留 5 个结果期间一直复用同一工作进程。全部关闭后它退出，再打开结果时启动新的工作进程；任一时刻最多一个，最后一个窗口关闭后的各采样点均为零子进程。独立观察器约每 100 ms 采样到的主/工作进程占用之和最大值为 **47.36 MiB**，可能漏掉短暂峰值。

从 5 个窗口关到只剩 1 个时，工作进程仍保留共享缓存，占用不会立刻回到首次只开 1 个窗口的水平；关完后才整体释放。第二轮刚关完的少量波动也在后续静置中回落。本次有限会话没有观察到残留工作进程或关闭后持续增长，不据此保证所有负载下绝对零泄漏。

## 真实调用与测试边界

- 本轮使用生产 `https://api.deepseek.com/chat/completions` 地址、原有模型和请求参数；没有启动本地响应服务。全部 TranslationCore 源码与正式应用逐字节相同，设置/钥匙串、IPC、截图和结果控件源码也未改变。
- 测量副本调用正常的 `AppDelegate()` 和钥匙串读取流程，未注入占位密钥，也未通过工具、命令行参数或文件读取/转存凭据。没有改动用户语言、快捷键、密钥或访问控制。
- 每次捕获的是专用公开英文窗口。发送前校验 PNG 必须与先前验证的公开内容逐字节一致：1740×940 像素、73,207 字节，SHA-256 为 `60487d35ab1031519dcc7c27736ec31f3fe874eac4f51e9157966cbf48802627`；不一致会在上传前终止。7 次均通过。只记录图片哈希、长度、结果完成状态和译文 UTF-8 字节数（111–120），不保存截图或译文正文。
- 结果实际显示在 AppKit 窗口中，采样前等到「翻译完成」且译文非空。关闭由测试副本在工作进程主线程调用原生窗口 `performClose(nil)`，走标题栏关闭与 `windowWillClose` 路径。主进程没有通过强制终止子进程来制造内存回落；正常空闲确认会结束工作进程。
- 诊断副本只增加入口驱动、完成/窗口计数、公开图哈希校验、原生关窗控制和阶段采样确认，相关开销包含在数值内。关窗控制的文件轮询仅存在于忽略目录中的测量副本，正式程序未添加轮询或诊断接口。
- 没有使用辅助功能或外部窗口截图查询应用，避免把界面观察工具的 AppKit 缓存混进结果。第一轮保留 5 个结果时额外检查关联服务：主进程 SetStore 为 3.047 MiB，工作进程 SetStore 为 2.531 MiB；第一轮关完后的检查确认工作进程及该 SetStore 均已退出。两轮结束时主进程关联 SetStore 约 3.016 MiB，无 ThemeWidget 或自动填充服务。第二个工作进程未在存活时单独取得服务快照，因此不将第一轮的服务退出检查扩展为对第二轮所有服务的独立证明。
- 阶段名称中的 3/15/45 秒是驱动的名义等待值。阶段采样确认和关联服务检查会增加实际等待，表格时间依据最后关窗计数文件的更新时间与采样时间计算；没有把重新启动后的冷启动值当作翻译后回落值。
- 这是同一短文本选区的顺序调用，验证多个已完成结果保留与最后关窗的资源回收；不同译文长度、大图、并行请求、多显示器和更长运行时间仍可能有不同占用。
